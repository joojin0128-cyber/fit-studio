# 헬스 스튜디오

휴대폰에 설치해 쓰는 개인 헬스 대시보드(PWA). 처음 설정한 키·체중·목표로 운동 프로그램과 식단을 **규칙만으로** 계산합니다.

- 기록은 **이 기기 브라우저 안(localStorage)에만** 저장됩니다. 서버 · 계정 · 외부 전송 · 분석 스크립트가 없습니다.
- 인터넷 없이도 열립니다(서비스워커).
- 규칙·데이터: `data/*.json`
- **인바디 결과지 사진 → 숫자**: 글자 읽기는 앱에 동봉한 [Tesseract.js](https://github.com/naptha/tesseract.js)(Apache-2.0, `vendor/tesseract/`)와 tessdata_fast 한글·영문 자료(`lang/`)로 **기기 안에서만** 합니다. 사진은 숫자를 읽은 뒤 버리고 숫자와 칸 위치(비율)만 저장합니다. 칸 고르기 규칙은 `inbody.js`, 화면은 `ibui.js`.

이 앱은 일반적인 운동·식단 정보를 규칙으로 계산해 보여 줄 뿐 의학적 조언이 아닙니다. 통증·질환·부상 이력이 있으면 운동 전에 의사·전문가와 상의하세요.
